# Streamlit-Sentiment-Analysis

IMP: Make sure all packages are installed in your local system before running the program.

1. This project is called Sentiment Scholar - a sentiment analysis bot.

2. It has 3 different modules - Direct, Chatbot and web-scrapping modules.

Direct Module: uses a <.csv> file and compares BERT NLP, ChatGPT and Gemini LLMs. (Note that all models are pre-trained) 

Chatbot Module: Uses ChatGPT to make a sentiment analysis AI bot. 

Web scrapping Module: Web-scrapes YouTube Comments and Websites. 

3. Please make sure that if you are running the website on your system, all files are present.

4. IMP: Make sure that you have entered the API for ChatGPT and Gemini LLMs in the config.json file. Without this, most of the program will not work. 

5. If there is a JSON error, please refresh the page. This error is common when <json> and ChatGPT an used together. If you have any queries, please email: sbalaji@memphis.edu

6. In order to run the streamlit app, go to Home.py file, open the terminal and run the command - 'streamlit run Home.py'
